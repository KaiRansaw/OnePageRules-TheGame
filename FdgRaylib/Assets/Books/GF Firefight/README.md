# GF Firefight army books

Empty on purpose. OPR publishes a separate army book per game system - the same unit can have
different points, unit size, available upgrades and even exist in one book and not another
(see WorkItems/406). These have never been downloaded, which is why a GF Firefight army currently
plays on its parent system's numbers.

Filling this folder is WorkItems/412; the runbook is the project doc `claude/army-forge-refresh.md`.
